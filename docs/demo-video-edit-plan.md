# Circles — demo video edit plan (≤30s for LinkedIn)

**Goal:** a tight, captioned, vertical-feeling clip that shows the *loop* and proves it's a real working app. LinkedIn autoplays muted, so captions carry it.

**Style:** lime-green accent (#A3E635), white text, semi-transparent dark rounded caption box, bottom-center. Quick fade in/out on each caption (~0.3s). Keep each beat ~3–5s.

## Trimming
- Cut any dead air: page loads, mouse hunting, mis-clicks, anything where nothing happens for >1s.
- Target total length **22–30s**. If it's running long, drop shot 2 (scrolling) first, then shot 5.
- Aim for one clear action per beat — don't show the same screen twice.

## Format
- Export **1080p MP4**, 30fps.
- If your recording is full-desktop width, **crop to the app column** (the centered ~480px-wide app) so it reads like a phone app. In Clipchamp: add the clip, then use Crop/zoom to frame just the app.
- Native upload to LinkedIn (don't post as a link) — native video gets far more reach.

## Music (optional)
- Add a low, upbeat royalty-free track from Clipchamp's built-in library at ~15–20% volume. Since it's muted on autoplay it's just for people who unmute.
